# DIY recipe · Bank Heist OOCSI Thing

**Deliverable:** `bank-heist.html`, one mobile HTML/CSS/JavaScript file. **Experience:** one navigator guides one infiltrator using radar position, a security map and LED cues. **Transport:** the course OOCSI Things system.

1. **Copy one file.** Download `bank-heist.html`. In Data Foundry, create a project with an existing dataset, upload the file, activate web access and select `bank-heist.html` as the Web Access Entry Point. See the [upload guide](DATA_FOUNDRY.md). Open its web link. Another static HTTPS host also works; no additional assets or software installation are required. [Course reference](https://oocsi.id.tue.nl/things/reference.html).
2. **Try it first.** Click Try offline demo in the opening dialog. Check setup, start, and move the simulated player with map buttons/arrow keys. No hardware or network connection is used.
3. **Choose a team for live play.** Return with Change team. Select e.g. Team 2; the course library uses `OOCSI-things/team-2`. Another group selects its own team. The old prototype used `OOCSI-things/team-2-bank-heist`; update the camera to match the new selection.
4. **Prepare the camera.** Build/flash [Concept1_Camera from the hardware repo](https://github.com/beraltan/team-2-hardware-module). On desktop Chrome/Edge open first-time camera setup, attach USB, and close serial monitors. Enter 2.4 GHz Wi-Fi/hotspot credentials, tick public camera publishing and choose the USB port. Settings go to the ESP32, which restarts. Confirm it appears in the camera selector; USB write success alone does not prove Wi-Fi connectivity. Untick publishing and save again to disable camera sharing.
5. **Prepare the room.** Default field: X −1.5…1.5 m, Y 1.5…3.5 m from a level radar. Mark START/VAULT from the map. Walk known marks, verify left/right and tracking, and keep the navigator behind the radar. Adjust dimensions/rules while idle, then confirm setup.
6. **Play.** Keep one controller visible with the screen awake. Infiltrator stands at START; navigator starts and holds direction cues. For someone facing the camera: left = +X, right = −X, forward = −Y, back = +Y. Release means STOP. Three anomalies cause lockdown; reaching VAULT wins. Inspect/reset after every attempt or fault.
7. **Connect your next puzzle.** Use `oocsiThings.data()` and `oocsiThings.link('toktik', 'state', ...)` in another Thing. Trigger once for each `toktik_round_id` when state is `won`. See the [message contract and example](INTERFACE.md). Change the theme in the sources and rebuild with `npm run build` if desired; ordinary adopters only need the HTML file.

OOCSI is public, and camera publishing continues after the browser disconnects. Screen sleep or network loss invalidates a running round. Physical tracking accuracy and LED comprehension require testing with the kit. Preserve [source attribution](../THIRD_PARTY.md); team-owned code is MIT licensed; upstream terms remain separate.
